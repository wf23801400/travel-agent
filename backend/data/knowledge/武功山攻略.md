# 武功山两天一夜攻略

## 最佳季节
5-10月是武功山最佳旅行季，草甸全绿，云海概率高。

## 交通
- **高铁**：坐到萍乡北站，出站有直达武功山的大巴（27元/人，约1.5小时）
- **自驾**：导航到武功山游客中心，停车费20元/天

## 行程安排

### Day 1
- 08:00 萍乡出发
- 10:00 到达游客中心，坐一级索道（中庵索道）上山，索道票65元
- 11:00 徒步至金顶，约2-3小时，路上经过吊马桩、草甸星空
- 14:00 到达金顶，拍照打卡
- 16:00 山顶住宿：金顶帐篷营地，约150-200元/顶（双人）
- 18:00 金顶看日落，绝美
- 19:00 帐篷区有简易餐饮，泡面+热水30元

### Day 2
- 05:30 金顶看日出+云海
- 07:00 收拾下山
- 08:00 走星空栈道方向下山，约4小时
- 12:00 到达山脚，游客中心附近吃萍乡炒粉（15元）
- 14:00 返程

## 费用预算
| 项目 | 费用（人均） |
|------|------------|
| 高铁往返 | 200-400元（视出发地） |
| 索道（单程） | 65元 |
| 门票 | 70元 |
| 山顶住宿 | 150-200元 |
| 餐饮 | 80-100元 |
| **总计** | **约 500-800元** |

## 注意事项
- 山顶温差大，带冲锋衣或薄羽绒服
- 防晒！海拔1900米紫外线强
- 带足水和干粮，山上物价高
- 帐篷需提前预订，旺季容易满
- 推荐装备：登山杖、头灯、雨衣
